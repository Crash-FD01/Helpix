Helpix apre ChatGPT, Claude, Gemini, Copilot o DeepSeek con il tuo account, incolla gli screenshot nella chat, esegue con un clic i comandi che l'IA ti propone e le riporta l'output. Open source, gratuito, solo quando lo chiedi tu.

Helpix opens ChatGPT, Claude, Gemini, Copilot or DeepSeek with your own account, pastes screenshots into the chat, runs the commands the AI suggests with one click and brings the output back. Open source, free, and only when you ask.

Aggiornamenti: arrivano insieme a quelli del sistema, con sudo apt upgrade, sudo dnf upgrade o sudo zypper update (e con Discover, GNOME Software, Gestore aggiornamenti).

Updates arrive with your system's: sudo apt upgrade, sudo dnf upgrade or sudo zypper update (and Discover, GNOME Software, Update Manager).

Preferisci farlo a mano? Debian, Ubuntu, MintRather do it by hand? Debian, Ubuntu, Mint 
sudo install -d -m 755 /etc/apt/keyrings
curl -fsSL @SITE_URL@/helpix.asc | sudo tee /etc/apt/keyrings/helpix.asc >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/helpix.asc] @APT_URL@ ./" | sudo tee /etc/apt/sources.list.d/helpix.list
sudo apt update && sudo apt install helpix
Fedora, RHEL, AlmaLinux, Rocky 
sudo rpm --import @SITE_URL@/helpix.asc
sudo curl -fsSL @SITE_URL@/helpix.repo -o /etc/yum.repos.d/helpix.repo
sudo dnf install helpix

Silverblue, Kinoite, Bazzite: come sopra, poi rpm-ostree install helpix e riavvia.

Silverblue, Kinoite, Bazzite: as above, then rpm-ostree install helpix and reboot.

openSUSE Tumbleweed, Leap 
sudo rpm --import @SITE_URL@/helpix.asc
sudo zypper addrepo --refresh @SITE_URL@/helpix.repo
sudo zypper install helpix
